    Python Lists · Cheat Sheet
    

    A quick guide to the list operations used in this lesson. All examples use our shopping list.
    

    

    CREATE
    Creating a list
    Put several values inside square brackets, separated by commas. Each value is an element.
    shopping_list = ["milk", "bread", "coffee"]
    

    INDEX
    Accessing an item · [index]
    Use an index to get one element. The first element has index 0; -1 means the last one.
    print(shopping_list[0])  # milk
print(shopping_list[-1]) # coffee
    

    CHANGE
    Changing an item
    Assign a new value to an existing index to replace that element.
    shopping_list[0] = "oat milk"
print(shopping_list)
    

    METHOD
    append() · Add an item
    Add one new element to the end of the list.
    shopping_list.append("bananas")
print(shopping_list)
    

    METHOD
    remove() · Remove an item
    Remove the first matching value. If it isn't in the list, Python raises an error.
    shopping_list.remove("bread")
print(shopping_list)
    

    FUNCTION
    len() · Count items
    Find how many elements the list currently contains.
    print(len(shopping_list))  # 3
    

    LOOP
    for ... in · Visit each item
    Run the indented code once for every element, in list order.
    for item in shopping_list:
    print("Buy:", item)
    

    CHECK
    in · Check whether an item exists
    Test membership before attempting to remove something.
    if "bread" in shopping_list:
    shopping_list.remove("bread")
    

    

    Putting it together
    

    Use a loop to show every item, then show the total.
    shopping_list = ["milk", "bread", "coffee"]
shopping_list.append("bananas")

for item in shopping_list:
    print("-", item)

print("Total items:", len(shopping_list))
    

    Remember: append() and remove() are list methods, called on a list with a dot. len() is a built-in function. Indexing ([0]), assignment (=), for, and in are Python syntax, not functions. These are the essential operations covered in Week 7.
